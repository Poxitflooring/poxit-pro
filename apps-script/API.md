# Poxit quote API

Three files go in the quote sheet's Apps Script project, next to the existing code (which keeps `doGet`):

| File | What it is |
|---|---|
| `PoxitInvoicing.gs` | `doPost`, Drive saving, invoice numbers, Invoice Requests |
| `PoxitApi.gs` | Quote API, shared quote numbers, Price Table tab, API Requests tab |
| `PoxitPricing.gs` | The tool's own pricing code, generated by `node tools/build-pricing.js`. Paste the new copy whenever pricing changes in the tool. |

Run `PXI_setup` then `PXA_setup` once. `PXA_showKey` logs the secret key, `PXA_rotateKey` replaces it.

## Two ways in

**Web app POST** to the deployment URL, body is JSON with `"action"` and `"key"`.

**API Requests tab** (for Claude through the Sheets connector): column A action, column B the request JSON (no key needed, the sheet is private). Within a minute the row gets Status, Quote Ref, Quote Key, totals, File ID, Link and the full result as JSON.

## Actions

`createQuote`
```json
{ "client": { "first": "Jane", "last": "Citizen", "phone": "", "email": "", "address": "12 Wave St",
              "suburb": "Burleigh Heads", "location": "Internal", "entity": "Company", "area": "Garage",
              "clientNotes": "" },
  "areas": [ { "type": "epoxy", "name": "Garage", "area": 45, "system": "Flake Internal", "finish": "Gloss",
               "walls": true, "wallM2": 6, "addons": { "nonslip": true } },
             { "type": "seal", "name": "Patio", "area": 30, "system": "Premium Next-Day Sealer", "finish": "Matte" } ],
  "travel": { "place": "Toowoomba", "km": 160 },
  "days": 3, "status": "Quoted", "showPrices": false, "pdf": true }
```
`client.location` (Internal, External or Both) is required. Area types: epoxy, tinted, seal, gs, aqua, grind, polished, care, shine, pw, comm. Any field the tool keeps on an area can be given. `travel`, `days` and `waste` are optional: left out, they fill in automatically like the tool. `state` can carry any other part of the quote (repairs, joints, demo, line marking).

`getQuoteByRef` `{ "ref": "PXT-2026-112", "client": "optional, if the ref was reused", "withState": false }`

`listQuotes` `{ "client": "jane", "status": "Quoted", "from": "1/11/2026", "to": "30/11/2026", "limit": 50 }`

`updateQuote` `{ "ref": "PXT-2026-112", "set": { "epoxyZones.0.area": 50 }, "merge": {}, "client": {}, "addAreas": [], "removeAreas": [{ "type": "seal", "index": 0 }], "lineEdits": { "seal-0": { "amount": 900 } }, "customItems": [{ "desc": "After hours access", "price": 120 }], "status": "Accepted" }`

`regeneratePdf` `{ "ref": "PXT-2026-112" }`

Every create, update and regenerate returns `ref`, `key`, `totals` (exGst, gst, incGst), `lines`, `days`, `fileId`, `link`, `fileName`. The PDF (real text) goes to the Quotes folder as `PXT-ref - Client - Address.pdf`, one file per quote updated in place, and the link, totals and date are written back to the quote's row. Nothing here sends email (see Invoices and email below).

## Payments (Nov 2026)

- `ledger` `{ "quoteKey": "PXT-1790…" }` (no key) lists every invoice for a quote: number, type, date, amount, paid, progress number, paid on time, early payment discount.
- `setPaid` `{ "key": "<secret>", "invNo": "INV-2026-050", "paid": true, "onTime": true }` ticks an invoice paid (and, for a Final with an early payment offer, whether it was paid on time).
- Invoice Requests now build the same invoice as the tool: payment history (only Paid invoices deducted, unpaid ones listed as outstanding), QBCC deposit limits for domestic jobs, progress invoices numbered per quote, early payment offer on finals.
- `doPost` is the project's only doPost. Anything it doesn't handle, and any body that isn't JSON, goes to `doGet(e)`.

## Invoices and email (19 Nov 2026)

- One invoice layout. The sheet builds invoices with the tool's own template (bundled in PoxitPricing.gs), so a sheet invoice and a tool invoice for the same job are the same document. Invoice numbers must look like `INV-YYYY-NNN` or nothing is made (no more "undefined").
- One invoice counter. `nextInvoice` `{ "localLast": 12 }` (no key) returns the next number after the highest one found in: the counter, the Invoices tab, the quotes tab (column O), the Drive Files index, file names in the Drive Invoices folder, and sent Gmail invoices (subjects and attachment names, cached 6 hours). The tool asks this before every invoice and only falls back to its own device counter, with a warning, when the sheet can't be reached.
- `showInvoiceNumbers` `{}` lists the numbers used and where, the highest, and the next.
- `setNextInvoiceNo` `{ "number": 40 }` sets the next number (refuses one already used).
- `renumberInvoice` `{ "invoiceNo": "INV-2026-001", "newNo": "optional" }` gives an unsent, unpaid invoice a new number: same Drive file rebuilt and renamed, Invoices tab, Drive Files index and quote row updated.
- `draftEmail` `{ "ref": "PXT-2026-125", "client": "optional", "doc": "quote" | "invoice", "invoiceNo": "optional", "to": ["a@b.com"], "cc": [], "subject": "...", "body": "plain text, sign off included" }` makes a Gmail draft from Dominic@poxitflooring.com.au with the latest PDF attached (quote: the quote's Drive PDF; invoice: that invoice, or the latest for the quote) and the signature appended. Returns `draftId`, `from`, `to`, `cc`, `subject`, `body`, `attachment`, `fileId`, `gmailLink`. Sends nothing.
- `sendDraft` `{ "draftId": "..." }` sends that exact draft and nothing else. Returns `messageId`, `sentAt`, `to`, `cc`, `subject`. Writes the date to the quote's Emailed column (S) and adds a row to the Email Log tab (Date, Quote Ref, Doc, To, Cc, Subject, Draft ID, Invoice No, Message ID, Attachment). A draft can only be sent once.
- Both email actions also work through the API Requests tab. Claude runs `sendDraft` only after Dom has said yes.

## Epoxy finish tiers (20 Nov 2026)

Flake and quartz epoxy areas take a finish: `"finishTier": "classic" | "gold" | "platinum" | "blackLabel"` (names like "Black Label" work too, and so does `"tier"` when it holds a finish name). Platinum takes `"platinumCoats": 1 | 2`. The uplift adds to the area's rate (Classic $0, Gold $15, Platinum $20 or $40, Black Label $50 per m²); Black Label drops non slip. Old quotes with the fast cure add-on on a flake or quartz area open as Platinum. Finish names and descriptions are text rows in the Price Table tab (unit "text") and print on the quote. New seal areas default to Premium Next-Day Sealer.

## Sanding and topcoat, post fit out check (21 Nov 2026)

- Area type `sandtop`: `{ "type": "sandtop", "area": 40, "system": "UV" | "polyaspartic", "finish": "Gloss", "second": true, "nonslip": false, "pwFirst": false }`. UV $30/m², polyaspartic $45/m², second coat $15 or $20/m², non slip $10/m², pressure clean first $8/m², $500 minimum across the job.
- Post fit out check lives in `state.fitout`: `{ "trades": true, "on": true, "hours": 0 }`. `trades` adds the other trades and floor protection terms; `on` adds the $250 visit (first hour included) plus `hours` at $200/hr. Never gets the bundle discount.
