# Installing the Poxit scripts in the quote sheet

1. Open the quote sheet, then Extensions > Apps Script. Leave the existing Code.gs as it is (it keeps doGet; it must not have its own doPost).
2. Make or update three script files, PoxitInvoicing, PoxitApi and PoxitPricing, with the exact contents of the matching .gs files in this folder. Save.
3. Services > Drive API > Add (once).
4. Run PXI_setup, then PXA_setup, then PXE_setup, and approve the permissions. Google will now also ask for Gmail access (to make drafts, send a draft Claude has been told to send, and read sent mail for invoice numbers). This adds or refreshes the tabs: Invoice Requests, Invoices, Drive Files, API Requests, Price Table, Email Log, and the Emailed column (S) on the quotes tab.
   If Project Settings shows "Show appsscript.json" ticked and that file lists `oauthScopes`, add `https://mail.google.com/` to the list. If there is no `oauthScopes` list, do nothing: Google works the scopes out itself.
5. Deploy > Manage deployments > edit the existing web app > Version: New version > Deploy. Same deployment, so the URL stays the same.
6. Run PXA_showKey to see the secret key in the execution log.

## Invoice numbers (Nov 2026)

7. Run PXI_showInvoiceNumbers. The log lists every invoice number already used this year and where it was found (Invoices tab, quotes tab, Drive Invoices folder, sent Gmail, the tool), the highest one, and the next number that will be issued. The tool and the sheet now share this one counter.
8. Run PXI_fixInvoice001. It renumbers the unsent invoice INV-2026-001 (Megan Madsen, PXT-2026-125) to the next free number, rebuilds its PDF on the same Drive file and updates the Invoices tab. It refuses if that invoice is ticked Paid or has been emailed.
   To force the next number by hand: PXI_setNextInvoiceNo(n) (refuses a number already used).

## Email

Nothing in the scripts sends email except the sendDraft action, which Claude runs only after Dom says yes out loud. draftEmail makes a Gmail draft with the latest quote or invoice PDF attached and Dom's signature (script property PXE_SIGNATURE, set by PXE_setup; change it with PXE_setSignature). Drafts come from Dominic@poxitflooring.com.au: if the script runs under another account it uses that address as a send-as alias, and if the alias isn't set up it returns an error instead of using another address.

Updating later: paste the new file contents over the old ones, save, run PXI_setup once (it refreshes headers), then step 5. PoxitPricing.gs is generated by `node tools/build-pricing.js`; paste the new copy whenever the tool's pricing or invoice layout changes.
