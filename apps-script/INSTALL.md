# Installing the Poxit scripts in the quote sheet

1. Open the quote sheet, then Extensions > Apps Script. Leave the existing Code.gs as it is (it keeps doGet; it must not have its own doPost).
2. Make or update three script files, PoxitInvoicing, PoxitApi and PoxitPricing, with the exact contents of the matching .gs files in this folder. Save.
3. Services > Drive API > Add (once).
4. Run PXI_setup, then PXA_setup, and approve the permissions. This adds or refreshes the tabs: Invoice Requests, Invoices, Drive Files, API Requests, Price Table.
5. Deploy > Manage deployments > edit the existing web app > Version: New version > Deploy. Same deployment, so the URL stays the same.
6. Run PXA_showKey to see the secret key in the execution log.

Updating later: paste the new file contents over the old ones, save, run PXI_setup once (it refreshes headers), then step 5. PoxitPricing.gs is generated by `node tools/build-pricing.js`; paste the new copy whenever the tool's pricing changes.
